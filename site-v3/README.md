# eSportsboost — V3 ("Classical" dark-editorial redesign)

A faithful, self-contained port of the **v3 design handoff**
(`Esportsboost website redesign (2).zip` → `design_handoff_esportsboost_v3`).

This is **completely separate** from the main site in `../site/` (port 4321). It does not
touch it, share code with it, or depend on it.

## What it is

- A single-page app with an in-app screen router — all nine screens from the handoff:
  Home, Game page, Configurator, Checkout, Order dashboard, Boosters, Coaching, Pricing, About.
- Plain vanilla HTML/CSS/JS. The handoff's proprietary `<x-dc>` runtime is **not** ported
  (per its own instructions); the state model, pricing math and markup were reimplemented.
- `classical.css` is the handoff's "Classical" design-system stylesheet, copied verbatim.

## Run it

```bash
python3 site-v3/serve.py 4322
```

Then open **http://localhost:4322**. (Stdlib only — no dependencies, like the main site.)

## Files

| File | What it is |
| --- | --- |
| `index.html` | Shell: `<head>`, `#app` mount, page-level CSS + responsive collapses |
| `app.js` | State, pricing model, and a render function per screen |
| `classical.css` | The design system tokens + component classes (verbatim from the handoff) |
| `serve.py` | Minimal static server on port 4322 |

## Notes / not-yet-done (from the handoff's own open items)

- **Pricing is display-only here.** A real deployment must recompute server-side (see the
  main site's `serve.py` / `pricing.py` for the pattern) — a client-computed commerce price
  is a coupon for anyone with devtools.
- **Imagery** — every slot is filled with **original, license-clean SVG key art** generated by
  `assets/gen_art.py` into `assets/keyart/` (abstract per-game emblem plates — no game screenshots
  or fan art, so nothing infringes studio IP). Swap any `assets/keyart/eb-*.svg` for licensed
  artwork later, or re-run `python3 site-v3/assets/gen_art.py` to regenerate. A labelled
  placeholder (`.eb-slot`) still shows if an art file is missing.
- **Responsive** was not in the handoff; `index.html` adds the recommended breakpoint collapses.
- Form fields (email, Discord, card) are visual only and unvalidated.
- Third-party game art/marks are not licensed — use original/licensed imagery for production.
